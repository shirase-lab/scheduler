# プライバシーポリシー — ShiraseLab Scheduler

最終更新日: 2026-10-04

本ポリシーは、ShiraseLab Scheduler（以下「本サービス」）が取り扱う情報について定めます。

## 1. 取得する情報

- **Google アカウント情報**: 認証時に、氏名・メールアドレス・プロフィール画像・ユーザー識別子(uid)を取得します（Firebase Authentication 経由）。
- **利用データ**: 作成した打ち合わせ（タイトル・内容・候補期間・所要時間・参加者メール・通知設定）、および各ユーザーが提出した希望日時（15分スロット）。

## 2. 利用目的

- 打ち合わせ日程の調整・集計・確定の提供。
- 確定内容の Google カレンダー登録、メール・Discord による通知。

## 3. 保存先と第三者提供

- **保存先**: Google Cloud Firestore（Firebase）。データは本サービスの Firebase プロジェクトに保存されます。
- **メール（招待・確定通知）**: 本サービスは**メール送信を行いません**。主催者の操作で **Gmail の作成画面**が、宛先・件名・本文をプリフィルした状態で開くだけで、送信するかは主催者自身が判断・実行します。送信内容は打ち合わせのタイトル・日時・候補期間・URL 等です。
- **Google カレンダー**: 打ち合わせ確定時に、ログインユーザー本人の権限（OAuth 同意に基づく）でカレンダーにイベントを作成し、参加者を招待します。
- **Discord**: 主催者がマスター設定に登録した Webhook URL へ送信します（設定した場合のみ）。
- 上記以外の第三者へ、本人の同意なく個人情報を提供・販売しません。

## 4. アクセス権限（OAuth スコープ）

- `calendar.events`: カレンダーへのイベント作成のため（これのみ）。
- メール送信は mailto（端末のメールソフト起動）で行うため、**Gmail 等のメール送信スコープは要求しません**。
- アクセストークンはブラウザのメモリ上で一時的に扱い、サーバーへ恒久保存しません。

## 5. アクセス制御

- Firestore のデータは、ログイン済みユーザーに対し必要範囲で公開されます（打ち合わせは URL を知るログインユーザーが閲覧可能、マスター設定は本人のみ、可否の書き込みは本人のみ）。詳細は `firestore.rules` に定義。

## 6. データの削除

- 打ち合わせは主催者が削除できます。アカウント/データの削除を希望する場合は運営者へご連絡ください。
