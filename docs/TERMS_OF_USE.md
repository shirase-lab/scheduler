# 利用規約 — ShiraseLab Scheduler

最終更新日: 2026-09-24

本規約は、ShiraseLab Scheduler（以下「本サービス」）の利用条件を定めます。利用者は本規約に同意のうえ利用するものとします。

## 1. アカウント

- 本サービスの利用には Google アカウントによる認証が必要です。
- アカウントの管理責任は利用者に帰属します。

## 2. 禁止事項

- 法令・公序良俗に反する行為。
- 他者のデータへの不正アクセス、なりすまし、サービスの妨害。
- 他者のメールアドレスを無断で参加者に登録し、望まない通知を送る行為。

## 3. 外部サービス連携

- 本サービスは Google カレンダー・Gmail・Discord と連携します。連携により送信される内容（イベント・メール・Discord メッセージ）の妥当性は、操作した利用者（主に主催者）の責任とします。
- Discord Webhook URL の登録・管理は利用者の責任で行ってください。

## 4. 通知に関する免責

- メール・Discord・カレンダー連携は外部サービスの状態に依存します。送達の遅延・失敗について本サービスは保証しません。確定結果はアプリ上の表示を正とします。

## 5. データの取り扱い

- データの取り扱いはプライバシーポリシー（`PRIVACY_POLICY.md`）に従います。
- 利用者が入力・提出した情報の正確性は利用者が負うものとします。

## 6. 免責事項

- 本サービスは現状有姿で提供され、特定目的への適合性等を保証しません。
- 本サービスの利用により生じた損害について、運営者は法令で認められる範囲で責任を負いません。

## 7. 規約の変更

- 本規約は必要に応じて変更し、変更時は最終更新日を更新します。
